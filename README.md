# CSV2SQLWizard

CSV2SQLWizard is a python application for converting CSV files to SQL tables with custom column types and data editing capabilities. This application provides a simple and intuitive graphical interface for transforming CSV data into SQL statements. The app allows you to edit column headers, specify SQL data types, modify cell values as needed, and generate CREATE TABLE and INSERT VALUE statements.

# Features

- Easy CSV Loading: Import any CSV file with a simple file dialog
- Interactive Data Table: View and edit data directly in the application
- Column Header Editing: Modify column names and set appropriate SQL data types
- SQL Data Type Support: Choose from VARCHAR, INT, FLOAT, DATE, TEXT, BOOLEAN, and DECIMAL
- SQL Generation: Automatically create SQL statements based on your data and column types
- SQL Preview: View the complete SQL in a dedicated window with proper formatting
- One-Click Copy: Copy the entire SQL script to clipboard with a single button
- SQL Export: Save the generated SQL to a file for later use

# Requirements

- Python 3.6+
- PyQt5
- pandas
